# 砖皮百科 · 画风设计（大框架）

给后续实现 Agent：本文只定视觉原则，不写具体 CSS/组件代码。站点代码暂不改。

参考：

- 编排气质：[Loop Agency](https://loop-agency.framer.website/)（dark）
- 色与线稿：[hud-line-art.png](hud-line-art.png)（坐姿战术线稿：绿黑 + 青绿描边；不再用夜视头盔 Snipaste 作底）
- 辅色层级：游戏内资讯条那种绿（当前态）+ 芥末黄（小标签）+ 深底

---

## 1. 一句话

Loop 的**编辑排版**（大留白、强字阶、选中极亮/其余极暗）+ 三角洲的**绿黑黄**，整体简约。流线**可以没有**。进入页靠两个能瞬间读懂的图标，并配短文案。

---

## 2. 不要做成什么样

现站（侧栏常驻、卡片描边、胶囊堆、青蓝到处描）像后台工具，缺高级感。禁止：

- 满屏同亮度灰白字
- 每个可点物都用同一套亮青描边
- 七列挤卡片、标签叠三层
- 常驻粗 HUD、四角准星图标当导航
- 中文正文全大写
- 为「高级」加厚重玻璃拟态、大渐变、花哨流线

---

## 3. 色板角色（用量克制）

实现时可从截图取色，但角色必须固定：

| 角色 | 方向 | 用法 |
|---|---|---|
| 底 | 绿黑 / 深青黑，接近线稿图，不是纯黑，也不是现站偏蓝灰 `#0b1318` | 全站底 |
| 主强调绿 | 夜视青绿 | 当前态、悬停主角、进入页选中项。一页里真正「亮绿」的点要少 |
| 辅黄 | 芥末金，小面积 | **仅优品**小标，不当大按钮底 |
| 极品幻彩 | 钻石虹彩（冰白 / 青 / 淡紫 / 香槟金） | **仅极品**小标，卡片底部同一矩形 |
| 主字 | 近白 | 超大标题、当前选中项 |
| 正文 | 银灰 | 说明、卡片名（非选中） |
| 元信息 | 再暗一级 | 日期、筛选旁注、角上小字 |

底可加极淡地形/十字纹理，透明度低到几乎感觉不到。

---

## 4. 流线

**当前决策：流线可以不明显，甚至不设。** 不要把分隔线当设计主角。若以后要加，只允许极细、弱光、少量，用在标题与内容之间；进入页不依赖中线讲故事。

---

## 5. 排版与字阶（学 Loop 的方法，不是抄黑白）

- **角上锚点：** 左上「首页」或品牌小字；右上最多一个弱操作。中间才是主角。
- **字阶拉开：** 一页只允许 1 个极大标题；其余刻意变小、变淡。
- **选中逻辑：** 当前项亮、邻项明显压暗（封面墙、上传三功能、枪种列表都如此）。
- **少按钮皮：** 能用字 + 细绿下划线当 Tab，就不用大色块圆角钮。
- **少框：** 高级感来自对齐和留白，不是圆角卡片墙。皮肤图可以有图，但减少描边和胶囊。
- **中文：** 展示级用字重/字距区分层级；说明用正常中文，不要英文站那种全大写段落。

字体：现站 `Segoe UI` + `微软雅黑` 偏工具感。后续可换更利落的无衬线（需考虑中文许可）。未换字体前，先靠字号、字重、颜色层级拉开。

---

## 6. 分页面视觉任务

### 进入页（第一印象）

全屏绿黑底，中间两个对等焦点：**图鉴** / **上传**。

- 图标必须一眼可读：图鉴偏「枪/图册」；上传偏「枪 + 上行箭头」或明确上传符号。不要抽象装饰标。
- **必须配短文案**（图标不够时文字兜底），例如：「图鉴 — 浏览已收录枪皮」「上传 — 投稿、待审、审核」。
- 悬停：该项放大变亮，另一项压暗；可出一小段简介。
- 点击：选中项居中放大，另一项淡出，再进下一页。这是**全站唯一过渡**。
- 四角可放极小品牌/版本，不要挤导航。

布局：**双焦点**，不是左右半屏硬切、也不是上下广告条。

### 选枪页

无侧栏。左上首页。大标题「选择枪械」（或等价短词）。下面疏封面网格：少列、大图、枪名即可。Hover 放大、邻卡变暗。无焚诀指南。

### 枪种图鉴页

此时才出现**薄枪种侧栏**（只切枪，无投稿/审核钮）。主区：大枪名 + 品质/材质/颜色文字筛选。皮肤小卡：优品金标、极品与筛选「炫彩」同底；材质、颜色用弱词条跟在后面。枪种教程图去掉。

### 上传选择页

三个大字项（上传新模板 / 查看待审 / 审批入口），同样一亮两暗。不要三枚一样大的 App 图标按钮。可各跟一行解释。

### 待审只读 / 审批 / 投稿多步

信息密度可以高于进入页，但仍用同一色板和字阶：标题亮、操作绿少用、黄只打标。审批页才出现通过/拒绝。只读待审**看起来像审核列表，只是没有操作条**。

---

## 7. 动效

- 仅进入页点击两个大入口做过渡（放大 + 另一项淡出）。
- 其余为短 hover（200ms 级缩放/亮度），不要页面间再套过场。
- 尊重 `prefers-reduced-motion`。

---

## 8. 给实现 Agent 的验收

- 打开站点先看到两个能读懂的入口 + 文字，而不是现首页封面墙。
- 扫一眼能分出「标题 / 正文 / 死信息」，不是满页同灰。
- 绿是当前态，黄是优品小标，钻石幻彩是极品小标，不是第二套按钮色。
- 没有装饰性流线也能成立。
- 图鉴路径侧栏不出现投稿/审核。
