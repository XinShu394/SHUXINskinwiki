# 砖皮百科 · 新 UI 提升过程

记录从现站到一阶段预览（`新UI资源/preview/`）的设计决策与修正。实现未并入 `site/`。

参考：[画风设计.md](画风设计.md) · [页面流程.md](页面流程.md) · [Loop Agency](https://loop-agency.framer.website/) · [线稿底](hud-line-art.png)

---

## 1. 起点：现站缺什么

现站（侧栏常驻 + 封面墙 + 焚诀指南）功能完整，观感偏后台：

- 字阶平，标题/标签/卡片名挤在相近灰白上
- 青蓝 `#38bde0` 同时当品牌、描边、按钮，处处亮则无处亮
- 卡片描边、胶囊、七列网格，呼吸感不足
- 「我要投稿 / 审核」缩在侧栏，上传注意力不够

目标：Loop 的编辑排版（大留白、强字阶、选中极亮）+ 三角洲绿黑黄，而不是照抄 Loop 黑白或堆 HUD。

---

## 2. 信息架构（已锁定）

```
进入页（图鉴 | 上传，双焦点 + 短文案，仅此处过渡）
  ├─ 图鉴 → 选枪页（现封面墙，无侧栏、无焚诀）
  │         └─ 某枪 → 图鉴页（薄枪种栏，无投稿/审核）→ 独立皮肤详情
  └─ 上传 → 三功能：新模板 / 只读待审 / 密钥审批
```

全局左上「首页」回进入页。待审公开字段与现审核列表所见一致（无通过/拒绝）。

---

## 3. 画风原则怎么落地

| 项 | 做法 |
|---|---|
| 配色 | 底绿黑 `#101c18`；主强调夜视绿只给当前态；辅黄只给**优品**小标；极品用钻石幻彩；字近白 / 银灰 / 更暗三级 |
| 字体 | 大标题 Barlow Condensed；正文 Noto Sans SC。投稿面板沿用现站 Segoe/雅黑，仅青改绿 |
| 留白 | 页边 clamp、网格大间隙；进入页/上传列表学 Loop「邻项压暗」，图鉴枪皮后来取消压暗 |
| 组件 | 无阴影、近直角、字按钮；筛选深色底避免系统白下拉 |

流线：讨论后决定可不做。进入页靠两个能读懂的图标 + 文字。

## 4. 预览迭代（按时间）

**v1 骨架**  
双焦点进入、选枪封面墙、图鉴接 OSS 真图、上传三分支。枪皮网格用了 Loop「未悬停压暗」——选枪困难，立刻改掉。

**观感修正**  
- 枪皮常亮，悬停只放大  
- 详情改独立页（不再页内下滚）  
- 上传/审批居中  
- 投稿改回现站居中面板  
- 整体略提亮，角标/筛选提高对比  

**黑底与大枪名**  
- 用户觉得绿底卡槽不高级，要求改黑  
- 枪名拉到接近 Loop 中间标题（约 `11vw`）  
- 标题旁接现站教程图  
- 投稿面板按视口比例放大（约 68vw × 82vh，有最小尺寸，手机近满宽）

**枪皮「底阴影」——本次**  

图1（早期预览）卡槽底是偏绿 `#1e322c`，和图页绿黑比较近，矩形不那么跳。  
图2（改纯黑之后）卡槽 CSS 底是 `#000`，页面是 `#101c18`，再叠加：

1. `aspect-ratio: 1.15` + `object-fit: contain` 在横图上下留出纯黑条，看起来像底阴影  
2. OSS 市场缩略图本身带游戏里的灰蓝底板，和绿黑页对不上  

处理：去掉独立色底板（透明），取消强制方框比，用 `mix-blend-mode: darken` 让图里偏亮的灰底板往页面暗色靠，枪皮亮部仍在。这不是加阴影，是去掉那块「假底板」。

**品级标 + 筛选选项卡**  

- 优品底框保持芥末金  
- 图鉴筛选：品质 / 材质 / 颜色文字选项卡（无对应字段的枪种藏行）  
- 颜色旁极小色点；双材质/双色按 `+` 分段匹配  

**小卡词条、极品炫彩底**  

- 枪封面小卡补材质、颜色词条（弱底，不抢品级）  
- 极品框与筛选「炫彩」共用 `--prism` 锥形渐变  
- 其后教程图已按反馈全部去掉（见下）

**线稿底 + 投稿第一页一屏见按钮——本次**  

- 全站底从图2夜视头盔 Snipaste 换成图1坐姿战术线稿 `hud-line-art.png`（`screen` 叠在绿黑上，线保留青绿）  
- 投稿面板钉死在视口内：顶栏 + 内容 + **底栏按钮始终可见**  
- 第一页两张引导图并排 `object-fit: contain`，缩进剩余高度，桌面不滚也能看到「下一步」

**排序对齐现站**  

- 图鉴排序改回现站的「默认 / 最热」  
- 热度公式与现站相同：点赞×1 + 评论×3  

**左下公告无框——本次**

- 现站侧栏「版本公告」「枪皮投稿/互动」文案与链接放到左下，无绿框
- 不含「我要投稿/审核」按钮
- 对照 GitHub `origin/main`：详情补充图、皮肤信息、点赞、评论、心得、lightbox 均在 `site/`，迁入时必须保留

**左下公告贴左、宽齐侧栏；选枪页隐藏**

- 当时 `.site-dock`：`left: 0`，宽度 `--rail`（160px）
- 其后按反馈整块去掉（见下）

**左下仅留 Q 群两行——本次**

- 版本公告、B 站 / UP 仍去掉
- 左下两行小字：`Q群:765759268` / `大家加群一起玩`，不换行
- 全站固定同一块：宽 `--rail`，左内边距 28px（与侧栏枪名对齐），右 20px，右缘不超过分割线

**迁入 site/——本次**

- 壳并入 `site/index.html` + `ui.css` + `app.js`，详情接回现站心得/点赞/评论/补充图/lightbox
- 投稿、审核仍用 `submit.js` / `review.js` 面板
- 未 push，线上未变
