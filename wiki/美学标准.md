# 知识库美学标准

这份文档规定知识库每个栏目长什么样、内容怎么写。新栏目、新文章照这里做，整个站看起来就是一套东西。

具体的文件夹和 Markdown 写法见 [补充指南](补充指南.md)。这里只讲「为什么这样」和「什么时候用哪一种」。

---

## 1. 总体气质

- **浅色档案风**：像一份整理好的资料档案。纸色底、墨黑字、细线分隔、淡淡的等高线背景。
- **克制**：颜色少，装饰少。让截图和枪皮本身成为画面里最亮的东西。
- **两种场景两种底色**：
  - 进入页（图鉴、知识库、上传三个入口）沿用砖皮百科主站的深色。
  - 知识库内部全部用浅色。
- **参考来源**：枪种入口的黑色方格参考 PRTS 首页，左侧栏参考终末地官网。

## 2. 颜色

### 2.1 色板

| 名称 | 色值 | 用在哪 |
|---|---|---|
| 纸色 | `#EEECE5` | 页面底色 |
| 卡片 | `#F7F6F1` | 卡片、引用框、表格底 |
| 墨黑 | `#121412` | 标题、重点文字、粗分隔线 |
| 正文 | `#3B403B` | 正文段落 |
| 次要 | `#757A73` | 摘要、说明、图注 |
| 弱化 | `#A3A79F` | 编号、待写、计数 |
| 细线 | 墨黑 11% | 普通分隔线 |
| 黑方格 | `#161917` | 枪种方格、图片衬底、例枪框 |
| 信号绿 | `#13A065` | 当前态、重点下划线、占比条 |
| 深绿 | `#0A6E45` | 绿色上的文字、链接 |
| 优品金 | `#B48A2C` | 只给优品，以及「易变」提示 |
| 极品幻彩 | 蓝、紫、橙、青四色渐变 | 只给极品 |

### 2.2 颜色规则

- **绿色只表示「当前」和「重点」**：当前所在的栏目、选中的选项卡、重点文字下划线、表格里的占比条。不要拿绿色做装饰。
- **金色只给优品，幻彩只给极品**。别的地方不要出现这两种颜色，否则读者会误以为跟品质有关。
- **文字永远是墨黑、正文或次要这几种灰**。不要用彩色写字，彩色只用在色块、圆点、线条上。

## 3. 字体

| 字体 | 用途 |
|---|---|
| Noto Sans SC（思源黑体） | 所有中文：标题、正文、按钮 |
| Barlow Condensed（窄体英文） | 枪名、大号数字、英文小标题，例如 `MARKET`、`06 章已更新` |
| JetBrains Mono（等宽） | 编号、路径、计数、标签，例如 `01`、`COLLECTION` |

- **标题**用 900 粗、字距略宽。页面大标题 36 到 64 像素，随屏幕宽度缩放。
- **正文** 16 像素，行高约 1.95，读起来松一点。
- **英文小标题**全大写，字距拉开（0.2em 到 0.3em），颜色用次要灰，跟在中文标题后面当副标题。

## 4. 版面

### 4.1 整体结构

- 左侧固定侧栏，宽 248 像素：头像、一级栏目、可展开的二级和三级目录、返回按钮、Q 群和审核入口。
- 右侧是主内容。最宽 1480 像素，超出部分居中，两边留纸色。
- 手机上侧栏变成顶部横向导航。

### 4.2 阅读页

- 阅读页是**正文列加右侧目录**两栏。正文列最宽 860 像素，和目录一起在屏幕中间。
- **文字和图片对齐同一条中线**，文字不用为了贴齐图片而拉宽。
- **单张图按原尺寸居中**，最高约占屏幕三分之二，不强制撑满整行。两到四张图排成网格。
- 表格、时间线、例枪框可以用满正文列宽。

### 4.3 留白

- 段落之间 16 像素，小节标题前留得更大，形成明显的段落感。
- 卡片内边距 24 到 32 像素。
- 宁可留白，也不要为了「填满」而放大图片或拉宽文字。

## 5. 组件

每种组件对应一种内容。写之前先想清楚这段内容属于哪一种。

| 组件 | 什么时候用 | 外观 |
|---|---|---|
| 先看这一段 | 每篇开头的结论，三到六句 | 卡片底，左侧绿色粗边 |
| 易变提示 | 写到价格、行情时自动出现 | 淡金底，左侧金色边 |
| 小节标题 `###` | 文章的大段落 | 墨黑粗体，下方细线；前面是黑底白字的两位编号，合集章节改用自带编号 |
| 四级标题 `####` | 小节里的细分 | 前面一个绿色空心方块 |
| 重点 `**加粗**` | 句子里的关键数字和结论 | 加粗，加浅绿色下划线 |
| 引用框（整行加粗） | 公式、引用他人的结论 | 卡片底，左侧墨黑粗边 |
| 看点 | 「看哪几处」这种部位细节 | 带编号的列表，电脑悬停在鼠标旁浮出特写，手机点开 |
| 例枪框 | 紧跟在看点后面的整枪图 | 黑底，左上角标「例枪 · SPECIMEN」 |
| 图片组 | 截图、对比图 | 一张居中，多张网格，点开看大图 |
| 表格 | 数据对比 | 表头细线，高亮行淡绿底；数字前加 ▮ 画占比条 |
| 时间线 | 有先后顺序的阶段 | 电脑横排、手机竖排，重点节点为绿色实心 |
| 图鉴卡片 | 推荐某一把具体的皮肤 | 从图鉴取图和标签，点进去是图鉴 |
| 视频卡片 | B站教程 | 一行一个，左边站点名，右边箭头 |
| 合集卡片 | 一套按顺序读的教程 | 左边章节目录，右边封面图径向淡出 |

### 5.1 重点怎么标

- **标数字和结论，不标整句**。例如「**一共花费 11000 三角券**」「磨损高的**建议选冰**」。
- 一段话里最多两三处。全是重点就等于没有重点。
- 表格里不加下划线，表格行要突出就把第一格加粗，整行会高亮。

### 5.2 图片

- 截图宽 1600 像素左右就够。超过 3 MB 的截图转成 JPG 再用。
- 看点的特写**裁到只剩那个部位**。悬停时特写会按原比例显示，最宽 340 像素。
- 封面类大图的主体放在画面偏右，网页会以主体为中心向四周淡出，左侧留给文字。

### 5.3 编号

- 枪种、章节、看点都用两位数编号：`01`、`02`。
- 合集里的章节标题自带编号，例如 `### 1.1 砖获取`、`#### 1.1.1 游戏内获取`。

## 6. 写作

- **短句**：一句话说一件事。
- **先结论后细节**：开头的「先看这一段」只写结论，正文再讲为什么。
- **用玩家的说法**：模板、磨损、公示期、抢购期、炼金，不造新词。
- **数据要写来源**：玩家样本要写明样本量，并注明「不代表官方概率」。
- **不确定的写进「不要写进回答」**：读者看不到，是给作者自己和后续整理用的备注。

## 7. 栏目模板

### 7.1 选皮焚诀：某把枪的优品、极品、通用

```text
## 先看这一段      看哪几处 + 最重要的一两条建议
## 正文
### 看哪几处       看点列表，紧跟一张例枪图
### 天气怎么选      或其他选法
### 配件颜色        可选
### 推荐模板        图片组或图鉴卡片
## 图鉴里看哪里
## 不要写进回答
```

参考：[腾龙 优品焚诀](内容/选皮焚诀/腾龙/优品/正文.md)。

### 7.2 砖皮市场机制：合集章节

```text
## 先看这一段      本章结论
## 正文
### 0.1 小节       自带章号编号
#### 0.1.1 细分
表格 / 时间线 / 视频卡片
## 不要写进回答
```

参考：[写给新手的一封情书](内容/市场焚诀/砖皮市场机制/00-写给新手的一封情书/合集.md)。

### 7.3 砖皮市场见闻

玩家通过网页投稿，不用照模板写。审核时只看标题是否说清楚这件事、正文有没有违规内容。

---

## 8. 不要做的事

- 不要用绿色、金色、幻彩以外的强调色。
- 不要让图片强制撑满整行。
- 不要整段加粗。
- 不要在正文里写 HTML。
- 不要把投稿入口放到砖皮市场见闻以外的地方。
