# 知识库预览

本地预览，用来和站点统一风格、排版。不进站点构建，不上线。

## 打开

直接双击 `wiki/preview/index.html` 即可。字体从 Google Fonts 加载，断网时会退回系统字体。

## 改完内容后刷新

```bash
python wiki/preview/build.py
```

内容怎么写、文件夹怎么放，看 `wiki/补充指南.md`。

## 试投稿和审核

```bash
python wiki/preview/run_api_local.py
```

在本机启动接口，数据存在 `wiki/preview/_local/`，不碰 `server/comments.db`，图片不传 OSS。审核密钥是 `local-admin`。不开这个命令也能看页面，只是市场焚诀的「玩家投稿」会显示连不上。

## 右下角两个开关

- **显示草稿**：关掉后只剩 `状态: 发布` 的篇目，也就是正式站会看到的样子。
- **编辑信息**：显示字数、草稿状态、待补段落、文件夹路径和「不要写进回答」。关掉就是读者视角。

## 结构

- 进入页保留站点深色，中间的入口叫「知识库」。
- 左侧栏：首页、选皮焚诀、市场焚诀。一级栏目点开才显示二级栏目。底部是投稿按钮和审核入口。
- 选皮焚诀：14 把枪，每把分优品、极品、通用三栏，空栏显示待补。
- 市场焚诀：砖皮市场机制、砖皮市场见闻。每栏上面是站长整理，下面是审核通过的玩家投稿。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` `preview.css` `preview.js` | 页面 |
| `build.py` | 扫描 `wiki/内容/`，生成 `data.js` |
| `data.js` | 生成的数据，不要手改 |
| `run_api_local.py` | 本地启动投稿接口 |
| `assets/` | 头像、等高线底纹；以后的横幅图放 `assets/hero.jpg` |
| `背景生图提示词.md` | 横幅和方格插画的生图要求 |
