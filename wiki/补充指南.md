# 知识库内容补充指南

一篇内容 = 一个文件夹。文件夹里放一个 `正文.md` 和这篇要用的图片。放好后运行一次下面的命令，预览就会更新：

```bash
python wiki/preview/build.py
```

命令会检查格式。哪里写错了、图片找不到、枪名写错，都会在终端里列出来。

预览没问题后，再运行一次带 `--site` 的命令，把内容发布到正式站的 `site/wiki/` 里，然后提交 Git：

```bash
python wiki/preview/build.py --site
```

它会把网页文件和压缩过的图片（最长边 1920、JPG）复制到 `site/wiki/`。`wiki/内容/` 里的原图不进 Git，只有 `site/wiki/` 里的压缩版会提交。

颜色、字体、版面、各种组件什么时候用，见 [美学标准](美学标准.md)。

## 文件夹怎么放

```text
wiki/内容/
├── _模板/正文.md                 复制这个开始写
├── 选皮焚诀/
│   ├── K416/
│   │   ├── 优品/                  这一格只有一篇：正文.md 和图片直接放这里
│   │   │   ├── 正文.md
│   │   │   ├── 枪头.jpg
│   │   │   └── 玉色.jpg
│   │   ├── 极品/                  空文件夹 = 网页上显示「待补」
│   │   └── 通用/
│   │   └── 通用/                  这一格有多篇时：每篇再建一个子文件夹
│   │       ├── 10-第一篇/正文.md
│   │       └── 20-第二篇/正文.md
│   └── …其余 12 把枪，文件夹都已经建好
└── 市场焚诀/
    ├── 砖皮市场机制/
    │   ├── 00-写给新手的一封情书/   合集，见下文
    │   ├── 10-挂单是怎么转的/正文.md
    │   └── 20-怎样算亏/正文.md
    └── 砖皮市场见闻/
        └── 10-你的一篇见闻/正文.md
```

### 选皮焚诀：补某把枪的优品、极品、通用

1. 打开 `wiki/内容/选皮焚诀/枪名/`，进入 `优品`、`极品` 或 `通用`。
2. 把 `_模板/正文.md` 复制进去，改内容。
3. 把这篇用到的图片放进同一个文件夹。
4. 运行 `build.py`。

不分优品极品的内容放 `通用`。同一格想写好几篇，就每篇建一个子文件夹。

### 市场焚诀：写一篇市场机制或见闻

1. 在 `砖皮市场机制` 或 `砖皮市场见闻` 下面新建一个文件夹，例如 `60-下架重上要注意什么`。
2. 放进 `正文.md` 和图片。
3. 运行 `build.py`。

玩家通过网页投稿的见闻不用放文件夹，审核通过后自动出现在「砖皮市场见闻」的「玩家投稿」里。

### 排序

文件夹名前面的数字就是排序，小的在前，例如 `10-`、`20-`、`30-`。用十位数，以后想在中间插一篇就用 `15-`。数字和横线不会显示在网页上。

## 正文.md 怎么写

### 开头信息

文件最上面用两行 `---` 包住。只有「标题」必填，其他不写也行。

```text
---
标题: K416 极品焚诀
摘要: 一句话说清这篇讲什么。
作者: SHUXIN
日期: 2026-10-21
状态: 草稿
易变: 否
---
```

| 字段 | 怎么填 |
|---|---|
| 标题 | 网页上的大标题。 |
| 摘要 | 列表里标题下面那行小字。 |
| 作者 | 显示在文章信息里。 |
| 日期 | 写完或改完的日期。 |
| 状态 | `草稿` 或 `发布`。草稿只在预览里能看到，正式网站只显示发布的。 |
| 易变 | 写到价格、行情、前瞻猜想就填 `是`，网页会提示「这是当时的经验」。 |

### 正文结构

```markdown
## 先看这一段

只写结论，三到六句。网页上会用绿色框单独突出。

## 正文

### 小标题

普通段落。空一行就是下一段。

## 图鉴里看哪里

- 武器：K416
  说明：看室内、室外两张持枪图

## 不要写进回答

- 不写具体成交价。
```

`先看这一段`、`图鉴里看哪里`、`不要写进回答` 都可以不写。不写 `## 正文` 也行，其余内容都算正文。`不要写进回答` 读者看不到，是写给自己的备注。

### 正文里能用的写法

**图片**：一行一张，括号里直接写同文件夹里的文件名。连续几行会自动排成一组。

```markdown
![官模下的玉色](玉色-官模.jpg)
![实战配件下的玉色](玉色-实战.jpg)
```

**看点**：列表每一项后面跟一张图。电脑上鼠标悬停出预览，手机上点开。适合「优品看哪五处」这种讲细节的地方。

```markdown
- 枪头：枪管前端的颜色和造型 ![枪头](枪头.jpg)
- 玉色：枪身内部玉石的颜色 ![玉色](玉色.jpg)
- 天气：不需要配图的项，后面不放图就行
```

看点列表后面紧跟一张整枪图，会显示成黑底的「例枪」框。特写图最好就是从这张例枪上截下来的：

```markdown
![例枪：优品腾龙](优品.png)
```

**图鉴卡片**：一行一个皮肤编号，或者直接粘贴图鉴详情页的网址。网页会自动取图鉴里的图、名字和标签，点进去就是图鉴。

```markdown
图鉴：K4-UG0100-001
https://skin.textagent.cn/#skin=K4-UQ0311-001
```

**链到另一篇**：用两层方括号包住那篇的标题。

```markdown
8999 这笔要不要等，详见 [[公示期要不要直接买]]。
```

**还没写完的地方**：读者看不到，预览里打开「编辑信息」才显示。

```markdown
**待补**：每一处单独截一张特写图。
```

**重点**：句子里用 `**加粗**` 包住的部分，网页上会加粗并带一道绿色下划线，适合关键数字和结论，例如 `**一共花费 11000 三角券**`。如果一整行都用 `**` 包住，会显示成单独的引用框，适合公式和引用。

其他：`- 普通列表`。不要写 HTML。

### 图片建议

- 文件名用中文或英文都行，不要带空格。
- 截图宽度 1600 像素左右就够，太大会拖慢网页。
- 讲细节的看点图，尽量裁成只剩那个部位。

## 合集：一套按顺序读的教程

「写给新手的一封情书」就是一个合集。合集是一个文件夹，里面放一个 `合集.md`，每一章是一个子文件夹：

```text
市场焚诀/砖皮市场机制/00-写给新手的一封情书/
├── 合集.md
├── 00-三角洲货币及充值/正文.md + 图片
├── 01-砖及钥匙获取/正文.md + 图片
├── 02-砖皮获取概览/正文.md + 图片
├── 03-磨损与成色/
├── 04-市场购买机制/
├── 05-炼金机制/
└── 封面-曼德尔砖.jpg
```

- 章节文件夹前面的数字就是章号，网页上的选项卡显示 00、01、02。
- 写新一章：新建 `06-章节名/`，放进 `正文.md` 和图片，运行 build.py。
- 合集可以放在市场焚诀的两个子栏目下，也可以放在某把枪的优品、极品、通用下面。

`合集.md` 的写法：

```text
---
标题: 写给新手的一封情书
副标题: 从 0 开始的入门教学
摘要: 合集卡片上的一句话介绍。
作者: SHUXIN
封面: 封面-曼德尔砖.jpg
状态: 草稿
---

合集页顶部的一段介绍。

## 后续章节

- 抽砖怎么抽
- 炼金怎么炼
```

「封面」写合集文件夹里的某张图，不写就用第一章的第一张图。封面会以图片右侧为中心向四周淡出，主体放在图片偏右的位置效果最好。「后续章节」是还没写的章节，网页上显示为灰色的「待写」选项卡。写好一章后，把它从这里删掉。

章节正文里的小标题可以自己带编号，例如 `### 1.1 砖获取`。再往下一级用四个井号：`#### 1.1.1 游戏内获取`。

## 表格

```markdown
| 档位 | 到账三角币 | 每元到账 |
|---|---|---|
| 328 元 | 4115 | ▮13.11 |
| **648 元** | 8425 | ▮13.74 |
```

- 第二行的 `|---|` 必须有。
- 第一格用 `**加粗**`，整行会高亮。
- 数字前加 `▮`，会画一条横向占比条，长度按这一列的最大值算。这个符号直接复制上面的就行。

## 时间线

单独一行写 `时间线：`，空一行，下面接一个列表。每项写成 `名称｜时长：说明`，名称用 `**加粗**` 会标成绿色重点。电脑上横排，手机上竖排。

```markdown
时间线：

- 卖家上架｜第 0 分钟：选好天数和价格。
- 公示期｜30 分钟：所有人能看，不能直接买。
- **抢购期**｜公示期结束的瞬间：系统抽出买家。
```

## 站外链接

正文里任何地方都能写 `[文字](网址)`。

如果一个列表里每一项都只有一个链接，会显示成视频卡片：

```markdown
- [【三角洲行动】入门教程第19期：三角币与三角券](https://www.bilibili.com/video/BV1c94tzNE3r/)
- [卖砖最细教程](https://www.bilibili.com/video/BV1uJWyzQE6T/)：冒号后面可以写一句说明
```

B站分享链接里的 `spm_id_from`、`vd_source` 这类跟踪参数会被自动去掉。

## B站知识库

侧栏的「B站知识库」读的是 `wiki/内容/外部链接.md`。一行一个链接，用 `### 小标题` 分组：

```markdown
### 入门

- [视频标题](https://www.bilibili.com/video/BV.../)：一句话说明
```

首页底部会显示前 4 条。

## 投稿入口

玩家投稿只在「砖皮市场见闻」页面有入口。砖皮市场机制由你自己写，按上面的文件夹方式补充。

---

## 玩家投稿和审核

「砖皮市场见闻」页面右上角有「投稿我的见闻」按钮。玩家填栏目、标题、署名、正文和最多 9 张图。正文里写 `[图1]` 就把第 1 张图放在那个位置。

提交后进入待审。审核员从侧栏底部的「审核入口」进入，用和图鉴审核同一把密钥。审核时可以改标题、换栏目，或者填理由拒绝。通过后投稿会出现在对应栏目，显示署名和投稿日期。

### 本地试投稿

```bash
python wiki/preview/run_api_local.py
```

这个命令在本机启动接口，数据存在 `wiki/preview/_local/`，不碰正式数据库，图片也不传 OSS。本地审核密钥是 `local-admin`。
